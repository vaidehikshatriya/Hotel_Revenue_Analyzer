# HOTEL REVENUE ANALYZER

## 1. Project Description

Hotel Revenue Analyzer is a Python-based application designed to analyze hotel revenue using data stored in a CSV file. It helps calculate daily revenue and revenue generated by different room types.

## 2. Project Objective

The main objectives of this project are:

- To calculate the total hotel revenue.
- To analyze daily revenue.
- To calculate revenue by room type.
- To identify the best revenue-generating day.
- To validate input data and skip invalid records.

## 3. Technologies Used

- Programming Language: Python
- Python Version: 3.14.8
- CSV Module
- Collections Module
- Math Module
- Visual Studio Code

## 4. Project Features

1. Reads hotel records from a CSV file.
2. Checks required columns.
3. Validates numeric values.
4. Skips invalid records with warnings.
5. Calculates daily revenue.
6. Calculates revenue by room type.
7. Displays total revenue.
8. Identifies the best revenue-generating day.

## 5. Input Dataset

The project uses a CSV file named "hotel_sales.csv".

Required columns:

- Date
- RoomType
- RoomsSold
- Rate

Revenue is calculated using:

Revenue = RoomsSold × Rate

## 6. How to Run the Project

1. Ensure the Python is installed on your system.
2. Open the project folder in Visual Studio Code.
3. Keep "hotel_revenue_analyzer.py" and "hotel_sales.csv" in the same folder.
4. Open the Python file.
5. Click Run Python File.
6. Enter "hotel_sales.csv" when prompted.
7. Select option 1 for Daily Revenue or option 2 for Revenue by Room Type.

## 7. Expected Output

The program displays:
• Daily revenue
• Total revenue
• Best revenue-generating day
• Revenue by room type
• Percentage contribution of each room type

## 8. Conclusion

The Hotel Revenue Analyzer successfully calculates and analyzes hotel revenue using Python and CSV data. It provides useful information about daily revenue, room-type revenue, and the best revenue-generating day.
