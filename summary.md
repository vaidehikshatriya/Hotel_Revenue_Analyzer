# HOTEL REVENUE ANALYZER

## 1. INTRODUCTION

Hotel Revenue Analyzer is a Python-based project developed to analyze hotel revenue using CSV data. The project processes hotel records and calculates revenue based on the number of rooms sold and their respective rates.

It provides two types of analysis: Daily Revenue and Revenue by Room Type.

## 2. PROBLEM STATEMENT

Hotels maintain records of rooms sold and their rates. Calculating and comparing revenue manually can be time-consuming.

This project provides a simple automated solution to calculate total revenue, analyze daily performance, and compare revenue generated by different room types.

## 3. OBJECTIVES

- To calculate daily hotel revenue.
- To calculate revenue by room type.
- To find the total revenue.
- To identify the best revenue-generating day.
- To validate the input data.
- To skip invalid records.

## 4. TECHNOLOGIES USED

- Python 3.14.8
- CSV Module
- Collections Module
- Math Module
- Visual Studio Code

## 5. INPUT DATASET

The project uses a CSV file named hotel_sales.csv.

The dataset contains four columns:

1. Date
2. RoomType
3. RoomsSold
4. Rate

## 6. METHODOLOGY

The project follows these steps:

1. Reads the CSV file using the CSV module.

2. Checks whether all required columns are available.

3. Validates RoomsSold and Rate values.

4. Skips invalid or incomplete records.

5. Calculates revenue using the formula:

  Revenue = RoomsSold × Rate

6. Groups revenue by date for daily analysis.

7. Groups revenue by room type.

8. Displays the total revenue and best revenue-generating day.

## 7. CODE EXPLANATION

CSV Module:
Used to read hotel records from the CSV file.

Collections Module:
The defaultdict function is used to group and calculate revenue by date and room type.

Math Module:
Used to check whether numeric values are valid and finite.

Main Function:
Controls the complete program execution.

Revenue Calculation:
RoomsSold is multiplied by Rate to calculate revenue.
